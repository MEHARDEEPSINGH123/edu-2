
EDUVANTA ACADEMY - PREMIUM EDUCATION PLATFORM GUIDE

BRAND
Eduvanta Academy

TAGLINE
Design Your Academic Journey

IMPORTANT DESIGN RULE

DO NOT USE:
- Trainer profile card grids
- Circular profile pictures
- Testimonial sliders
- Generic education website layouts
- Hero + Courses + Reviews structure
- Traditional tuition centre templates
- Repeating UI patterns used in previous projects

CORE IDEA

Create an Academic Journey Platform.

The website should feel like:
- Apple Education
- MasterClass
- Notion
- Modern Learning Product

NOT:
- Tuition website
- School directory
- LMS dashboard

NAVIGATION

Use a dynamic academic pathway navigation.

Users can enter through:

PSLE
O-Level
A-Level
IB
IGCSE
Skills Development

The entire website adapts around the selected pathway.

UI CONCEPT

Instead of showing courses first:

Show a student's future journey.

Example:

Current Level
↓
Academic Goal
↓
Recommended Path
↓
Course Selection
↓
Trial Class
↓
Admission

This becomes the main UX.
